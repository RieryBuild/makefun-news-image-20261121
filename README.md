## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) validates `entry.png` (PNG magic, IHDR 1024×1024, IEND, ≤1 MiB) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). Two runs are byte-identical.
